# Tip Calculator enhancements

- Quick-select 10%, 15%, 18%, and 20% tip presets alongside the slider.
- Live bill, tip, total, and per-person calculations.
- Adjustable party size and a reset action.

## Structure

- `lib/main.dart`: calculator UI and derived calculations.
- `test/calculation_test.dart`: sample split calculation.
- `test/widget_test.dart`: calculator interaction coverage.

## Demo checklist

1. Change the bill amount and observe live totals.
2. Pick a preset and adjust the slider.
3. Change the party size and check the per-person amount.
4. Reset the calculator.
